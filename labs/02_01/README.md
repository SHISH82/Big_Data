# Лабораторная работа 02_01

1. Сгенерировать модельный ряд: `x_k = sqrt(k*h) + norm(0,1)`, `k = 0,…,500`, `h = 0.05`.

2. Выделить тренд методом простого скользящего среднего с шириной окна 21, 51, 111 (`m = 10, 25, 55`).

3. Выделить тренд методом скользящей медианы с шириной окна 21, 51, 111.

4. Сравнить полученные тренды с точным значением и сделать выводы.

5. Вычесть тренды из ряда и проверить остатки на случайность по числу поворотных точек и коэффициенту Кендела.
