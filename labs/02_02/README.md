# Лабораторная работа 02_02

Сгенерировать модельный ряд: `x_k = 0.5*sin(k*h) + norm(0,1)`, `k = 0,…,500`, `h = 0.1`.

1. Выделить тренд методом экспоненциального скользящего среднего с коэффициентами `α = 0.01, 0.05, 0.1, 0.3`.

2. Сравнить полученные тренды с точным значением и сделать выводы.

3. Вычислить амплитудный спектр Фурье для этого модельного ряда и определить его главную частоту.

4. Вычесть тренды из ряда и проверить остатки на случайность, несмещённость их средних и нормальность.
