# Лабораторная работа № 1

1. Создать два вектора: `x = -10, -9, ..., 5`; `y = -5, -4, ..., 10`.

2. Построить новый вектор `z`, в котором на нечётных местах будут стоять элементы вектора `x`, а на чётных — элементы вектора `y`. Отсортировать элементы полученного вектора.

3. Написать функцию, вычисляющую нормы вектора, и найти нормы векторов `x`, `y`, `z`.

4. Написать функцию, вычисляющую факториал числа.

5. Создать вектор, состоящий из 5 элементов, и веса с помощью ввода с клавиатуры.
   Найти минимальный и максимальный элементы вектора по модулю, а также сумму элементов вектора и весовую норму.
