# Лабораторная работа № 1

Создать два вектора: `x = -10, -9, ..., 5`; `y = -5, -4, ..., 10`.

1. Построить новый вектор `z`, в котором на нечётных местах будут стоять элементы вектора `x`, а на чётных — элементы вектора `y`. Отсортировать элементы полученного вектора.
2. Написать функцию, вычисляющую нормы вектора, и найти нормы векторов `x`, `y`, `z`.
3. Написать функцию, вычисляющую факториал числа.
4. Создать вектор, состоящий из 5 элементов, и веса с помощью ввода с клавиатуры. Найти минимальный и максимальный элементы вектора по модулю, а также сумму элементов вектора и весовую норму.
